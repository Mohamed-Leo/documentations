# Building Brand Identities — Agent Skill

A reusable Agent Skills package for developing a complete brand identity from discovery through activation. It is designed for businesses, products, services, software platforms, teams, organizations, and sub-brands.

## What it covers

- Brand discovery and market research
- Mission, vision, purpose, values, audience, positioning, promise, differentiation
- Naming territories, candidate generation, scorecards, preliminary clearance
- Brand story, tagline, descriptor, slogans, messaging pillars, proof points, CTAs, bios and boilerplates
- Voice, tone, vocabulary and writing rules
- Logo strategy and identity directions
- Color, typography, imagery, iconography, graphic devices, layout and motion
- Arabic/English bilingual identity considerations
- Brand guidelines, applications, rollout and governance
- Quality gates for strategic, verbal, visual, legal-risk and accessibility checks

## Install / use

Keep the directory intact so `SKILL.md` can reference the supporting files. Install it in a runtime that supports the Agent Skills format, or place it in that runtime's recognized skills directory.

The core workflow lives in `SKILL.md`. Detailed frameworks are intentionally split into `references/` so the main skill stays readable and agents load depth only when required.

## Recommended invocation

Examples:

- “Use building-brand-identities to create a complete identity for my new software company.”
- “Use building-brand-identities to evaluate these five names and continue the identity from the winner.”
- “Use building-brand-identities to rebrand us without losing recognition.”
- “Use building-brand-identities to build an Arabic/English identity and messaging system.”

## Important boundaries

The skill can perform preliminary name/domain/social/trademark research, but it must not represent that work as legal clearance or legal advice. Final trademark clearance should be handled through the relevant official registries and, where risk matters, a qualified trademark professional.
