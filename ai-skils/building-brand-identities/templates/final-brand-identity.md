# Complete Brand Identity — Deliverable Template

## 1. Executive summary
- Brand idea in one paragraph
- Recommended direction
- Why it fits the business and audience
- Current readiness level

## 2. Brief and evidence
- Business / audience / market
- Constraints
- Key research findings
- Category patterns and whitespace
- Assumptions and unresolved questions

## 3. Brand strategy
- Purpose
- Vision
- Mission
- Values + behaviors
- Primary audience
- Competitive frame
- Value proposition
- Positioning statement
- Brand promise
- Reasons to believe
- Personality: trait / not-trait
- Brand architecture

## 4. Naming
- Naming criteria
- Naming territories
- Shortlist scorecard
- Recommended name and rationale
- Pronunciation / spelling
- Meaning / story
- Bilingual forms if relevant
- Preliminary domain/social/trademark notes
- Legal-clearance caveat / next steps

## 5. Verbal identity
- One-line description
- Brand story
- Elevator pitch
- Boilerplate
- Tagline
- Alternative tagline directions
- Messaging pillars + proof
- Audience-specific messages
- Hero headline/subhead examples
- CTA library
- Social bio
- Voice principles
- Tone matrix
- Preferred / avoided vocabulary

## 6. Visual identity concept
For each explored territory:
- strategic idea
- visual keywords
- symbol/form logic
- palette direction
- type direction
- imagery direction
- graphic/motion behavior
- differentiation
- risk

Then state the selected/recommended territory and why.

## 7. Logo system
- Logo concept / symbolism
- Primary lockup
- Secondary lockups
- Symbol / wordmark
- Monochrome/reversed
- Small-use/icon version
- Bilingual lockups
- Clear space
- Minimum size
- Background rules
- Misuse
- Production asset status

## 8. Color system
Table: Role | Name | HEX | RGB | CMYK/Pantone if verified | Use | Contrast notes

## 9. Typography
Table: Role | Typeface | Weights | Use | Language support | Fallback | License status

## 10. Imagery / illustration / iconography
- observable art-direction rules
- do / don't examples
- icon construction principles

## 11. Graphic system / layout / motion
- graphic devices
- patterns
- grids / spacing / density
- motion principles
- reduced-motion behavior

## 12. Applications
Show or specify the highest-priority real touchpoints.

## 13. Brand guidelines and governance
- source of truth
- owner / approvals
- asset structure
- versioning
- exception process
- review cadence

## 14. Quality-gate results
- strategic coherence
- naming/legal-risk
- verbal identity
- visual identity
- accessibility
- production readiness

## 15. Next actions
Prioritized list of decisions, production tasks, legal review, asset creation and rollout items.
