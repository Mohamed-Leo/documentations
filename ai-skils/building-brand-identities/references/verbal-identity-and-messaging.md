# Verbal Identity and Messaging

## Build a system, not a tagline

Separate the layers below so each has a clear job.

### Core narrative
- **Brand story:** origin/tension → belief → approach → outcome.
- **One-line description:** plain-language explanation of what the brand is.
- **Elevator pitch:** 30–60 second explanation for a new audience.
- **Boilerplate:** reusable company description for press, profiles and partners.

### Messaging hierarchy

1. **Positioning** — internal strategic frame.
2. **Brand promise** — recurring customer expectation.
3. **Value proposition** — why the offer is valuable and different.
4. **Messaging pillars** — usually 3–5 themes supporting the promise.
5. **Proof points** — evidence for each pillar.
6. **Audience messages** — adaptations by segment/use case.
7. **Channel messages** — adaptations by context without changing the core truth.

### Marketing language set

Create as relevant:
- descriptor / category line
- tagline options
- campaign slogan directions
- hero headlines and subheads
- short value propositions
- CTA library
- social bio variants
- sales intro
- email intro/sign-off patterns
- product feature naming principles
- launch lines

**Tagline vs slogan:** treat the tagline as a long-lived expression of the brand; treat campaign slogans as temporary creative lines for a specific campaign or moment.

## Voice

Define 3–5 stable voice principles. Each principle must include:
- trait
- what it means in writing
- what it does **not** mean
- on-brand example
- off-brand example

Example pattern: **Clear, not simplistic.** Explain complexity in direct language; do not remove necessary nuance.

## Tone matrix

Voice stays recognizable; tone changes with context. Define tone by situation, for example:
- homepage / awareness
- sales
- onboarding
- success / celebration
- error / failure
- complaint / support
- crisis / sensitive communication
- technical documentation
- social media

For each context set levels for formality, energy, humor, directness and empathy.

## Vocabulary system

Document:
- preferred words
- avoided words / clichés
- product/category terminology
- capitalization rules
- punctuation/emojis when relevant
- claims requiring evidence
- inclusive / culturally sensitive language rules
- Arabic/English terminology mapping when bilingual

## Messaging quality gate

Copy should be:
- specific enough to belong to this brand
- understandable without internal context
- supportable by proof
- consistent with positioning
- adaptable to multiple channels
- recognizably voiced even without the logo

Reject generic lines that could be pasted onto most competitors.
