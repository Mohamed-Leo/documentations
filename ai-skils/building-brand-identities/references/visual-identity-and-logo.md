# Visual Identity and Logo System

## Start with creative territories

Before final logo work, create 3 distinct identity territories. Each should contain:
- strategic idea
- 3–6 visual keywords
- symbol/form logic
- composition/layout behavior
- color direction
- typography direction
- imagery/illustration direction
- graphic device/pattern idea
- motion behavior if digital
- what makes the territory ownable
- main risk / cliché to avoid

Territories must differ in concept, not just color.

## Logo system

### Concept
The logo should identify the brand quickly and express a relevant idea without trying to explain the entire business.

Evaluate:
- distinctiveness
- appropriateness for audience/category
- memorability
- legibility
- simplicity without genericness
- scalability
- one-color performance
- small-size performance
- reproduction on light/dark/complex backgrounds
- digital icon/app/favicon use
- print/signage/embroidery constraints when relevant
- relationship to bilingual wordmarks
- ability to support future architecture

### Required variants
As applicable:
- primary lockup
- horizontal / stacked alternative
- symbol-only
- wordmark-only
- monochrome positive
- reversed / knockout
- small-use variant
- favicon/app/social avatar
- bilingual lockups

### Usage rules
Document:
- clear space
- minimum size
- background rules
- approved colorways
- alignment
- partner/co-brand lockups if needed
- misuse examples: stretching, recoloring, effects, rotation, crowding, low contrast, rearrangement

## Color system

Define roles, not a pile of swatches:
- primary brand colors
- secondary/supporting colors
- neutrals
- accents
- functional UI colors when applicable

Record HEX/RGB for digital and CMYK/Pantone only when properly specified for print production. Do not invent an exact Pantone match from HEX alone; label approximations.

Create an accessibility matrix for important text/background combinations. For digital UI, aim for WCAG AA contrast: generally 4.5:1 for normal text, 3:1 for large text, and 3:1 for relevant non-text UI boundaries/graphics. Logo marks themselves have an exception, but brand-system applications should still be usable.

## Typography

Define:
- primary and secondary families
- display/body/UI roles
- weights
- hierarchy
- size/line-height/spacing principles
- numerals and language support
- web/office fallbacks
- licensing constraints

For bilingual brands, choose Latin and Arabic families with compatible visual color, proportions and hierarchy rather than forcing identical shapes.

## Imagery and illustration

Specify:
- subject matter
- composition
- lighting
- color treatment
- realism/abstraction level
- human representation
- texture/grain
- cropping
- do/don't examples

Avoid vague guidance like “premium photography.” Define observable characteristics.

## Iconography and graphic devices

Define icon stroke/fill, corner language, grid, detail level, optical size, and when icons are functional vs decorative. Define patterns, shapes, lines, frames, grids or modular devices that can create recognition beyond the logo.

## Layout and motion

For digital-first brands define:
- grid and spacing character
- density
- radius/border/shadow behavior if relevant
- motion principles
- logo animation behavior
- transitions and easing character
- reduced-motion alternative

Motion should reinforce the brand idea, not become decoration.

## Deliverable reality check

A concept image is not automatically a production-ready logo. Final identity work should eventually have clean vector masters and appropriate export formats. If the agent cannot produce vectors, state that clearly and provide construction specifications rather than claiming completion.
