# Guidelines, Applications and Activation

## Turn identity into an operating system

A brand guide should let a new teammate create correct work without guessing.

## Recommended guideline structure

1. Brand overview
2. Purpose / vision / mission
3. Values
4. Audience
5. Positioning / promise / value proposition
6. Personality
7. Brand story
8. Naming / pronunciation when useful
9. Messaging hierarchy
10. Voice principles
11. Tone by context
12. Vocabulary / writing style
13. Logo concept
14. Logo variants
15. Clear space / minimum sizes
16. Logo misuse
17. Color palette and roles
18. Accessibility-safe color pairs
19. Typography and hierarchy
20. Photography / imagery
21. Illustration
22. Iconography
23. Graphic devices / patterns
24. Layout / spacing
25. Motion
26. Bilingual rules when applicable
27. Co-branding / partnerships when applicable
28. Example applications
29. Asset/file organization
30. Governance / owner / version / review cadence

Only include sections that are meaningful to the brand, but do not omit usage rules for core assets.

## Applications

Choose applications based on actual touchpoints. Typical examples:
- website hero and page language
- app/UI sample
- social profile + post system
- presentation/deck cover
- sales one-pager
- email signature/newsletter
- business card/stationery
- packaging/label
- signage
- event booth
- merch/uniform
- paid ad

Mockups demonstrate behavior; they are not a substitute for the underlying rules.

## Launch / rebrand rollout

Create a prioritized migration inventory:
- legal/company records when relevant
- domain and DNS
- website/app
- product UI
- social profiles
- email systems
- sales decks/templates
- customer communications
- packaging/signage
- ads
- partner assets
- internal docs

Classify each item by owner, dependency, deadline and risk.

## Governance

Document:
- source-of-truth location
- brand owner/approver
- version/date
- approved asset library
- who can adapt vs who must request approval
- review cadence
- how exceptions are recorded

A brand system should be maintainable. Avoid guidelines that freeze every future decision or depend on one designer's memory.
