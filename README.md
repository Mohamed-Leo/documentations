# Documentation Directory Structure

The `DOCUMENTATIONS` folder contains various guides and references to ensure best practices in coding, workflows, and configurations. Below is the structure and purpose of each subdirectory and file.

```plaintext
DOCUMENTATIONS/                # Documentation files
├── gift-lub-workflow/         # Git workflow
│   └── WORKFLOW.md            # Documentation about Git workflow
└── husky/                     # Husky setup and usage
    ├── README.md              # Documentation about Husky
└── README.md                  # General information about Husky configuration
```
